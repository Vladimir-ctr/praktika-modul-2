# Проект к модулю 2 "Осуществление транзакций между пользователями"

# Проект содержит код, демонтсрирующий осуществелние транзакций между пользователями.
**В проекте есть несколько веток. Каждая ветка несет в себе дополнения к предидущей.**

**Всего 4 ветки:**
- v1 - создание структуры для хранения пользователей, методов для снятия и пополнения средств и проведение нескольких операций снятия/пополнения
- v2 - Создание структур Transaction представляющую транзакции и PaymentSystem которая хранит информацию о пользователях и транзакциях. Реализация методов добавления пользователей, добавления транзакций и обработки транзакций. Реализация переводов между клиентами.
- v3 - создание функции worker, канала и запуск нескольких горутин. Увеличения скорости обработки транзакций и производительности.
- v4 - для защиты доступа к Balance добавляем Mutex чтобы не возникло состояния гонки.

# Запуск проекта
1. Создайте папку для проекта в удобном Вам месте
2. Убедитесь что у Вас на компьютере установлен GIT
3. Откройте папку в VS Code через проводник - в строке пути удалите путь и введите команду "code ."
4. Откройте терминал и выполните команду "git clone https://github.com/Vladimir-ctr/praktika-modul-2.git"
5. После этого у Вас появилась отдельная папка praktika-modul-2 в которую Вы можете перейти и посмотреть ее содержимое с помощью команды "cd praktika-modul-2"
6. Папка содержит 3 файла:
    - go.mod - информация о модуле
    - main.go - файл с кодом программы
    - README.md - инструкция и описание 
7. Перейдите в файл main.go откройте терминал и выполните команду "go run main.go"
